# AI Knowledge Assistant 🤖

> A full-stack GenAI application that allows users to upload documents, search their knowledge base using semantic retrieval, and have citation-backed conversations using Retrieval-Augmented Generation (RAG).

---

## 📌 Overview

AI models are powerful, but they don't automatically know the private information contained in a user's documents.

The **AI Knowledge Assistant** solves this by allowing users to upload documents and interact with them using natural language.

The application processes uploaded documents, converts their content into vector embeddings, stores them in a vector database, retrieves relevant information for a user's query, and provides an answer using an LLM.

The goal is to build a **production-style RAG application** while learning the backend and GenAI technologies involved in building modern AI applications.

The main goals of this project are to gain practical experience with:

- Backend development
- REST APIs
- Databases
- Authentication
- Document processing
- Embeddings
- Vector databases
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- Streaming responses
- RAG evaluation
- Docker
- AI application observability

---

# 🧑‍💻 What Can the User Do?

A user will be able to:

1. Create an account
2. Upload documents
3. View their uploaded documents
4. Ask questions about their documents
5. Receive AI-generated answers
6. View the sources used to generate the answer
7. Continue conversations using chat history
8. Delete documents
9. Manage multiple conversations
